idea中java打包教程

发表于2026-03-01|更新于2026-03-01|学习系统问题java
|浏览量:
  • 点击顶部菜单栏的 File → Project Structure（快捷键：⌘;）
  • 在左侧面板选择 Artifacts
  • 点击 + 按钮，选择 JAR → From modules with dependencies...
  • 在弹出的对话框中，选择 App 类作为主类（Main Class）
  • 确保 Extract to the target JAR 选项被选中

点击 OK

  • 点击顶部菜单栏的 Build → Build Artifacts...
  • 在弹出的菜单中，选择您刚才创建的Artifact，然后点击 Build

构建完成后，在配置的输出目录中可以找到生成的JAR文件
